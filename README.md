# Network Infrastructure Lab

## Descripción
Laboratorio personal para practicar diseño, administración,
seguridad y monitorización de redes.

## Objetivos
- Implementar redes segmentadas mediante VLAN.
- Configurar routing y reglas de firewall.
- Administrar acceso remoto mediante VPN.
- Monitorizar servicios y dispositivos de red.
- Documentar pruebas y resolución de problemas.

## Tecnologías
- OPNsense
- Cisco Switching
- MikroTik
- Proxmox VE
- WireGuard
- Pi-hole
- Zabbix

## Arquitectura
El laboratorio integra un firewall, switches administrables,
servicios DNS, virtualización y herramientas de monitorización.

## Proyectos
- [ ] Segmentación de red mediante VLAN.
- [ ] Firewall y políticas de acceso.
- [ ] Acceso remoto mediante WireGuard.
- [ ] Monitorización con Zabbix.
- [ ] Infraestructura virtualizada con Proxmox.
